## 冷续接端口夹具

74c650a 普通全量 Go CI、三个原生专项与 T26 通过，独立 T25-V04 的原20次重复在 `TestAlignmentProfileDedicatedColdResume/stream=true` 报旧端口可连接。日志没有记录连接到的监听器身份，不能据此倒认具体内核复用顺序。

独立临时 overlay 强制第二个 gateway 使用首个已关闭的端口，先验证旧监听器 ECONNREFUSED，再验证真实 cold resume、token/env 轮换、旧 token 得401、新 token initialize 得200，原事后 TCP 探针仍失败。这证明探针不能区分旧网关和端口的新持有者。

原 QA owner 在 Close 后立即检验并保留旧端口，固定本夹具所需的不同 URL；Windows 仅精确地址占用10048并且连接拒绝10061可代替重新绑定，其他错误失败。保持100ms原限额，保留session nonce、manifest原文、URL/env/token轮换检查；新增未关闭监听器的严格失败反例。生产 gateway 未修改。
