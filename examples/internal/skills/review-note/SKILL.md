# Review Note

Use this skill only when the prompt explicitly tells you to use `review-note`.

## Steps

1. Read the requested change or artifact from the prompt.
2. Produce a single concise review note.
3. Keep the note focused on the requested review scope.
4. Do not modify files unless the prompt explicitly asks for it.
